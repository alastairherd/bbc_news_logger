# Ask the archive surface brief

Scope: /signals/ inside the established shell. Mode: Operate. Audience: researchers asking a
question of the archive. Job: search by meaning, optionally get an answer that cites only the
retrieved BBC stories, and check every claim against its numbered source. Data: semantic index via
the existing worker; shared Cloudflare answer service or the visitor's own DeepSeek key.

## Direction contract

THESIS: A question box over numbered sources, with the answer set as a cited brief above them;
it refuses the chat-product default of a conversation thread and the old dark answer panel.

OWN-WORLD: White canvas, ink type, hairline rules, ink primary button turning red on hover,
surface-grey answer block under a 2px ink rule, ink citation badges, red LIVE and Most Read tags.

STORY: The visitor asks, sees status while the model loads, reads a cited answer, follows a
citation to its numbered source, and opens the BBC article or the archive record.

FIRST VIEWPORT: Title and one line; status bar (labelled, searchable stories, model state); large
query input with Ask and Find sources buttons; four filters; summary line; key disclosure.

FORM: Extension of the established Overview world. seed: none (roll skipped: direction pinned by the user)
Pin, in the user's words: "I'm looking at a visual overhaul in line with the design pattern that
exists on the standard https://www.bbc.co.uk/news website" and "I would like to use the BBC red,
and that's that". The user chose to split Ask & analyse into two pages.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
